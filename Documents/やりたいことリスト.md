# やりたいことリスト

**「あとでやりたい」と思ったことを書き溜めておく場所。**

作業中に思いついたことは、そのとき手を止めてやるのではなく、ここに書いて先に進む。
忘れないために書く場所であって、**ここに書いたら必ずやる、というものではない。**

## 書き方のルール

- 誰でも書いてよい。AIが代わりに書き足してもよい。
- **やったら行を消さずに、状態を「完了」に変える。** いつ何をやったかが残る。
- **やらないと決めたものは「見送り」にして、理由を書く。** 同じ話が何度も出るのを防ぐため。
- 不具合や「危ないところ」は、ここではなく `リスクリスト.md` に書く。
- 誰かの判断が必要なことは、ここではなく `質問リスト.md` に書く。

| 状態 | 意味 |
| --- | --- |
| `未着手` | まだ手を付けていない |
| `作業中` | 誰かがやっている |
| `完了` | やった。**いつ・何をしたかを続けて書く** |
| `見送り` | やらないと決めた。**理由を続けて書く** |
