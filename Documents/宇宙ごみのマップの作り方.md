| 項目 | 内容 |
| --- | --- |

| 対象 | **宇宙ごみ集め**のステージ（マップ）を作る人（プログラマー・デザイナー） |

> 釣りのステージの作り方は別。`機能ドキュメント/釣りのマップ作りとマップ選び.md` を見ること。
> 遊び方や勝ち方は `機能ドキュメント/宇宙ごみ集めの対戦.md`。

---

## まず知っておくこと

- マップは **1つのシーン**。置き場所は `Assets/Scenes/Prototype/SpaceJunk/`
- **シーンの名前は半角の英数字**（例：`SpaceJunkMap05`）。日本語・スペースは使わない
- **いちばん簡単で確実なのは、今あるマップを複製して作り変えること**（下の「作り方」）
- シーンは同時に2人で編集できない。**触る前に Discord で一声かける**

---

## マップに必要なもの

| 必要なもの | 数 | 無いとどうなるか |
| --- | --- | --- |
| ラウンドの進行役（`SpaceJunkRound`） | 1個 | ラウンドが始まらない。イベントもここで動く |
| ゴール（`SpaceJunkGoal`） | **遊ぶチーム数に合わせる**（下の表） | 自分のゴールが無いチームは、絶対にラウンドを取れない |
| デブリのスポナー（`SpaceJunkSpawner`） | 1個 | デブリが降ってこない |
| プレイ中の画面（`SpaceJunkMatchUI`） | 1個 | 残り時間や得点が出ない |
| カメラとフックのゲージ | 1つずつ | 画面が映らない・ゲージが出ない |

地面・壁・障害物などの地形は自由に作ってよい。

### ゴールの数と、遊べるチーム数

ゴールは **Goal Index** で方角を決める：**0＝北、1＝東、2＝南、3＝西**。

| 置いたゴール | 遊べるチーム数 | 使われ方 |
| --- | --- | --- |
| 北・東・南・西（4つ） | 1〜4チーム | 2チームなら北と南、3チームなら北・東・南、4チームなら全部 |
| 北・南 | 1〜2チーム | 2チームなら 北＝青・南＝赤 |
| **東・西** | 1〜2チーム | 2チームなら **東＝青・西＝赤**（北と南がそろっていないときだけ東西を使う） |
| 北・東・南 | 1〜3チーム | |
| 1つだけ | 1チームだけ（1人で試す用） | |

- **ロビーは、いまのチーム数で遊べないマップを候補から自動で外す**（例：3チームにすると、東西1対1のマップは出ない）
- 選んであったマップが遊べなくなったとき（チーム数を増やしたとき）も、自動で外れる

## 作り方

### 1. 複製する

- Project で `Assets/Scenes/Prototype/SpaceJunk/SpaceJunkMap01.unity` を選んで **Ctrl+D**
- 名前を半角の英数字に変える（例：`SpaceJunkMap05`）
- **エクスプローラーでコピーしない。** Unity の中で複製すると、通信で使う番号（NetworkObject の番号）が新しいシーン用に付け直される。エクスプローラーでコピーすると番号がかぶって、オンラインで正しく動かない

> 1対1（東西）のマップなら、メニューの **`Tools > StarSweepers > 宇宙ごみの東西1対1のマップを作る（Map01を複製）`** で、
> 複製・北と南のゴールの取り除き・一覧への登録まで一度にできる（`SpaceJunkMapDuelEW` ができる）。

### 2. 地形を作る

- 地面・壁・障害物を置き換える
- **上の「必要なもの」は消さない**

### 3. ゴールを置く

- 遊ばせたいチーム数に合わせて、上の表のとおりに置く
- ゴールを足すときは、**今あるマップのゴール（`Goal_〜` という名前の物）をコピーして貼り付け**、`SpaceJunkGoal` の **Goal Index** を空いている方角の番号にする
- ⚠️ **釣りの `Assets/Prefabs/Fish/Online/GoalArea.prefab` をそのまま置いてはいけない。** あれは**釣りのゴール**で、宇宙ごみのゴール（`SpaceJunkGoal`）が付いていない。
  置くと「〇〇チームのゴールが、このマップにありません」になって遊べない（2026/10/1 に実際に起きた）
  - 置いてしまったときは、そのマップを開いて **`Tools > StarSweepers > 開いているマップの釣りのゴールを宇宙ごみのゴールに直す`** を実行する。
    宇宙ごみのゴールに付け替え、**置き場所から方角（Goal Index）を自動で決めて**保存する（中心から見て 奥＝北・右＝東・手前＝南・左＝西）
- ゴールのインスペクターに **`SpaceJunkGoal` が出ているか**で見分けられる（`FishingNetPocket` なら釣りのゴール）
- **同じ番号のゴールを2つ置かない**（点検でエラーになる）

### 4. デブリが降る範囲を合わせる

- `SpaceJunkSpawner` の **Area Half Size**（初期値 16m × 16m）を床の広さに合わせる
- シーン画面でスポナーを選ぶと、範囲が**緑の枠**で見える

### 5. マップの一覧に入れる

- メニュー **`Tools > StarSweepers > 宇宙ごみのマップの一覧を開く`**
- インスペクターの Maps に、作ったシーンを Project からドラッグして足す
  - **Show In Lobby**：ロビーの候補に出すか。**作りかけのうちは外しておく**
  - **Display Name**：ロビーに出す名前（空ならシーンの名前）
- 一覧に入れると、ロビーの候補と検証用ビルドに自動で入る

### 6. 点検する

- メニュー **`Tools > StarSweepers > 宇宙ごみのマップを点検する（作り直さない）`**
- Console に「点検OK（ゴール 東・西 → 2チームまで …）」のように出れば、必要なものはそろっている
- **赤いエラーが出たら直す**
- 点検のときに、**どの方角にゴールがあるかが一覧に控えられる**（ロビーはこれを見て候補を絞る）。
  **ゴールを足したり消したりしたら、点検をもう一度実行すること**

### 7. 試す

- メニュー **`Tools > StarSweepers > 宇宙ごみ集めの検証用のビルドを作る`** で `.exe` を作り、ロビーでそのマップを選んで遊ぶ
- **エディタの再生では1人分しか動かない。** 複数人で試すときはビルドを使う（`.bat` で2人・4人・8人を自動でつなげる）

## 気をつけること

| 決まり | 理由 |
| --- | --- |
| **ステージの中心は原点（0, 0, 0）** | プレイヤーは自分のゴールから中心へ4m寄った場所に出てきて、中心のほうを向く |
| **床は高さ -8m より上** | -8m より下に落ちると、自動で出てくる場所へ戻される |
| 床のまわりに壁を置く | 落ちると3秒動けなくなる（復活時間） |
| 地形の見た目は、**プレハブから切り離して**作る | 今あるマップは釣りのプレハブと繋がったままで、釣り側を直すと一緒に変わってしまう（`リスクリスト.md`） |
| シーンを編集したら、コミットのときに**編集したと伝える** | シーンは自動でマージできないため |
