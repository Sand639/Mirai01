# 機能と検証シーンの一覧

**いまプロジェクトにある機能を、1枚で見渡すための早見表。**

機能ドキュメントが増えて、「何があるのか」「どのシーンを開けば試せるのか」が
ファイルを1つずつ開かないと分からなくなってきたため作った（2026/9/14）。

- 詳しい中身は、各行の「ドキュメント」列のファイル（`機能ドキュメント/` の中）を読むこと。
- **機能を追加したら、ここにも1行足す。** 状態が変わったら書き換える。
- 「状態」は、**人が実際に遊んで確かめたかどうか**を基準にしている（AIはUnityの再生で操作を確かめられないため）。

## Unityのメニュー（`Tools > Mirai01`）

AIが作った「置くためのツール」と「作り直すためのツール」の一覧。

### 置くツール（いま開いているシーンに足すだけ。**消えるものは無い**）

| メニュー | 置かれるもの |
| --- | --- |
| `ロープを1本置く` | 縦のロープ（6m） |
| `横向きのロープを置く` | 横のロープ（うんてい） |
| `踏むボタンと動く壁を置く` | ボタンと壁が繋がった1組 |
| `鍵と鍵付きの扉を置く` | 鍵と扉の1組 |
| `ガラスの板を置く` | 3m × 2.5m × 8cm のガラス板 |
| `重力で割れるガラスの床を置く` | 割れるガラスの床1枚 |
| `爆弾を置く` | 爆弾1個 |
| `釣りのアンカー検証シーンを作る` | 青いキューブの固定アンカーを置いた検証シーンとプレハブ |
| `ポーズ画面を置く` | ポーズ画面（**置かなくても自動で出る**。見た目をシーンごとに変えたいときだけ使う） |
| `ロボットにロープ機能を足す` | `RobotRig.prefab` にロープ機能を足す（**すでに付いていれば何もしない**） |
