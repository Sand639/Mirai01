## この機能は何か

**目の前にある物を複製して、好きな場所に置ける機能。**

脱出ゲームの核になる遊びとして作った。
**置いた物を足場にして高い所へ登る**、という遊び方を想定している。

置ける数には上限があり、超えると**一番古いものから消えていく**。
そのため「どこに置くか」を考える必要が生まれる。

---

## 遊ぶ人から見た動き

画面の中央に**照準（レティクル）**が出ている。これが狙いの位置。

**狙った物は色が変わる**ので、「これに対して操作できる」と一目で分かる。

| 狙っている物 | 色の変化 |
| --- | --- |
| **複製できる物**（`Duplicable`） | **水色**になる。Eで複製できる |
| **自分が置いた物**（`PlacedClone`） | **橙色**になる。Rで消せる |
| それ以外 | 変わらない |

色が変わると、あわせて**レティクルも同じ色になり、少し大きくなる**。

| 操作 | 結果 |
| --- | --- |
| **E** | 見ている物を複製する。半透明ではなく**緑色**の状態で出てくる（まだ置いていない印） |
| **マウスを動かす** | 複製した物が、見ている場所に付いてくる |
| **左クリック** | その場所に**確定して置く**。ここで初めて落下や当たり判定が働く |
| **Escape** | 置くのをやめる（複製した物は消える） |
| **R** | 自分が置いた物を見て押すと、**その物を消す** |

### 置ける数の制限

- 初期設定では**5個**まで置ける
- 6個目を置くと、**一番最初に置いた物が消える**
- 消える前に**0.5秒間、赤く点滅して知らせる**（いきなり消えると理由が分からないため）

### 物によって重さが違う

| 複製元 | 重さ | 特徴 |
| --- | --- | --- |
| **CloneSourceLightBox**（黄色い箱） | 1 | 軽い。押すと動く |
| **CloneSourceHeavyBox**（灰色の箱） | 30 | 重い。安定した足場になる |
| **CloneSourceFragilePlank**（桃色の板） | 2 | **強くぶつかると壊れる**。上から重い物を落とすと砕ける |

壊れやすい板は、**軽い物を静かに乗せる分には壊れない**。
重い箱を上から落とすと壊れる。「重さを考えて積む」遊びを作るための仕掛け。

## すぐ試す方法

1. Unityで `Assets/Scenes/Test/ObjectClonerTest.unity` を開く
2. **再生ボタンを押す**

正面に複製元が3つ並んでいる。後ろを向くと**緑色の高台**があるので、
箱を複製して積み、登って到達できるかを試せる。

### 使っているタグ

ツールの実行時に**自動で登録される**ので、手で作る必要はない。

| タグ | 意味 |
| --- | --- |
| `Duplicable` | 複製できる物に付ける。これが付いていない物はEを押しても複製されない |
| `PlacedClone` | 自分が置いた複製に、置いた瞬間に自動で付く。Rキーで消せるのはこれだけ |

**新しく複製できる物を増やしたいときは、`Duplicable` タグを付けて `Rigidbody` を付けるだけでよい。**

## 自分のシーンで使う方法

1. `PlayerRig` をシーンに置く
2. `PlayerRig` に **`ObjectCloner`** コンポーネントを追加する
3. インスペクターで次の3つをつなぐ
   - `Aim Camera` … `PlayerRig` の中の `PlayerCamera`
   - `Player Root` … `PlayerRig` 自身
   - `Input Actions` … `Assets/InputSystem_Actions`
4. 複製させたい物に `Duplicable` タグと `Rigidbody` を付ける

## 設定できる値（インスペクターの項目）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Pick Distance | 複製したい物を狙える距離（m） | 10 |
| Place Distance | 置き場所を探せる距離（m） | 30 |
| **Max Placed Objects** | **同時に置ける数** | 5 |
| Warning Seconds | 消える前に点滅する時間（秒） | 0.5 |
| Warning Color | 点滅の色 | 赤 |
| Place Offset | 床から少し浮かせる量（m） | 0.02 |
| Preview Color | 置く前の色 | 緑 |
| **Highlight Color** | **複製できる物を狙ったときの色** | **水色** |
| Removable Color | 自分が置いた物を狙ったときの色 | 橙 |
| Reticle | 画面中央の照準。空でも動く | PlayerRig の Reticle |
| Pick / Cancel / Remove Key | 各操作のキー | E / Escape / R |

`FragileObject`（壊れる板）側の設定：

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| **Break Impulse** | この強さ以上でぶつかると壊れる。**小さくすると壊れやすい** | 12 |
| Safe Seconds | 置いた直後、壊れないようにする時間（秒） | 0.4 |
| Piece Count | 壊れたときの破片の数 | 6 |

## 仕組み（分かる人向け）

- 設計は依頼時の参考コードを踏襲している。
  **プレビュー中は物理オフ（`isKinematic = true` / `Collider.enabled = false`）、確定時に有効化**、
  配置順は **`Queue<GameObject>`** で管理する
- 狙いは**画面中央からのRaycast**。参考コードは `ScreenPointToRay(Input.mousePosition)` だったが、
  一人称でカーソルを画面中央に固定しているため、**カメラ正面へのRayに変更**した
- **自分自身とプレビュー中の物はRayの対象から外している。** 除外しないと、
  カメラがキャラクターのカプセルの内側にあるため自分に当たって前に進まない
- 置く位置は、当たった面の法線方向に**物の高さの半分だけ持ち上げて**いる。
  そのまま置くと床にめり込むため
- 壊れる判定は `OnCollisionEnter` の **`collision.impulse`**（ぶつかった瞬間の勢い）で見ている。
  質量と速度の両方が効くので、**重い物ほど遅くても壊せる**

### 参考コードから変えたところ

| 変えた点 | 理由 |
| --- | --- |
| `Input.GetKeyDown` → **Input System** | このプロジェクトは Input System に統一する決まりのため |
| マウス位置のRay → **画面中央からのRay** | 一人称でカーソルを固定しているため |
| 自分自身をRayから除外 | カメラがカプセルの内側にあり、自分に当たってしまうため |
| 色を戻す処理を作り直し | **一度 `renderer.material` に触ると `sharedMaterial` も複製側を指すようになり、元の色を取り出せなくなる**ため、変える前に色を控える方式にした |
| 削除時にキューを作り直す処理を修正 | 元のコードは新しいキューを作って差し替えていたが、`readonly` で保持する形にしたため中身を詰め直す方式にした |

## できていないこと・既知の問題

- **動作確認はUnityの再生で行っていない。** コンパイルが通ることと、
  参照が正しくつながっていることまでは確認済み。**実際の操作感は未確認**
- **置く向きは変えられない。** 仕様書には「回転も自由」とあるが、
  まず1〜4を動かすことを優先した。回転は次の段階で足せる
- **他の物と重なっていても置ける。** 壁の中や他の箱の中にも置けてしまう。
  プロトタイプでは困らないと判断した（`リスクリスト.md` に登録済み）
- **プレビュー中は半透明ではなく色だけ変えている。** 半透明にするにはマテリアルの
  設定変更が必要で、複製元ごとに影響が出るため避けた
- **置ける数を画面に表示していない。** いま何個置いてあるかは見えない。
  `ObjectCloner.PlacedCount` と `MaxPlacedObjects` を公開してあるので、UIから読める
