## この機能は何か

**Escape を押すと開く、ポーズ画面。** 開いている間、**ゲームは止まる。**

| 項目 | 押すとどうなるか |
| --- | --- |
| **ゲームをつづける** | 画面を閉じて、続きから遊ぶ |
| **設定** | 音量とマウス感度を変える画面へ |
| **ゲームをやめる** | ゲームを終了する（**エディタでは再生を止めるだけ**） |

**マウスで選ぶ。** もう一度 Escape を押しても閉じられる。

---

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| **Escape** | **ポーズ画面が開く。** 後ろが暗くなり、ゲームが止まる。マウスカーソルが出る |
| **項目にマウスを重ねる** | **色が変わり、少し大きくなり、左に「▶」が出る** |
| **項目をクリック** | その項目が実行される |
| **Escape**（開いている間） | 閉じて、続きから遊ぶ |

**閉じるとカーソルは消えて、視点操作に戻る。**

### マウスが重なったときの見せ方

**3つ同時に変えている。** 1つだけだと気づかれにくいため。

- **色**が明るくなる
- **少しだけ大きくなる**（5%）
- **左に「▶」が出る**

変化は**なめらかに**動く。ポーズ中でも動くように、**止まっても進む時間**を使っている。

### 設定の画面

| 項目 | 内容 |
| --- | --- |
| **音量** | ゲーム全体の音の大きさ |
| **マウス感度** | 視点を回す速さの倍率（1でそのまま） |

**次に遊ぶときも、変えた値は残る**（パソコンに保存している）。

## シーンに置く手順

**置かなくてよい。** どのシーンでも、**再生すると自動で用意される。**

置き忘れたまま「Escape を押しても何も起きない」と悩むことが多いため、
**シーンのどこにも無ければ、ゲーム側が自分で1つ作る**ようにしてある。

見た目や色を**そのシーンだけ変えたい**ときは、手で置けばそちらが使われる。

1. 置きたいシーンを開く
2. メニューの **`Tools > Mirai01 > ポーズ画面を置く`** を実行

**カメラもUIも要らない**（足りない物はこちらで作る）。

> **止まっている間は、シーンに何も見えない。**
> 画面は**再生したときに組み立てられる**ため（理由は下に書いてある）。
> 再生して Escape を押すと出てくる。

## 仕組み（分かる人向け）

### 画面をコードで組み立てている理由

**プレハブに画面を作り込んでいない。** 再生したときに、`PauseMenu` が自分で作る。

理由は**日本語のため。**
Unityに最初から入っている文字は**日本語を持っていない**ので、
そのままだと項目名が**四角（□□□）**になってしまう。

**パソコンに入っている日本語フォントを借りてくる**必要があるが、
それは**保存できない**（プレハブに残らない）。
そのため、画面を作るところまで含めてコードにしてある。

> **日本語のフォントを持つ形（TextMeshProの日本語フォント）を用意すれば、
> 普通にプレハブで作れるようになる。** 見た目を凝りたくなったら、そのとき作り直すのがよい。

### Escape の取り合い

**Escape は、もともとカメラ側が「カーソルを出す」ために使っていた。**
そのままだと、ポーズ画面と取り合いになる。

**「止まっている間だけカメラが手を引く」では足りなかった。**
閉じる瞬間は**同じ1フレームの中で**「止まっていない」に戻るため、
そのあとにカメラ側が同じ Escape をもう一度拾ってしまい、
**閉じたのにカーソルが出たまま**になっていた。

そこで、**ポーズ画面があるなら Escape はカメラ側では一切見ない**ことにした。

| | ポーズ画面があるとき | 無いとき |
| --- | --- | --- |
| カメラ | **Escape を見ない**（クリックでカーソルを固定するのは今までどおり） | Escape でカーソルを出す |
| ポーズ画面 | Escape で開く／閉じる | ― |

あわせて、**ポーズ画面は他の部品より先に動く**ようにした（`DefaultExecutionOrder(-100)`）。
順番が決まっていないと、同じフレームでの取り合いが再び起きるため。

**複製配置システムも Escape を「やめる」に使っている。**
止まっている間は入力を受け取らないようにしたので、
ポーズ画面を開いても**置きかけの複製が消えない。**

### 止まっているのに動かしたいもの

`Time.timeScale` を 0 にすると、**歩く・落ちるは自動的に止まる。**
ただし2つだけ、自分で気をつける必要がある。

- **マウスでの視点移動は止まらない**（動いた量をそのまま使っているため）
  → `GamePause.IsPaused` を見て止めている
- **`Time.deltaTime` が 0 になる**ので、そのままだとUIのアニメーションも止まる
  → マウスが重なったときの変化は `Time.unscaledDeltaTime` を使っている

### クリックを受け取る仕組み

UIのクリックには `EventSystem` が要る。**無ければ自動で作る。**

このプロジェクトは**新しい入力方式（Input System）**を使っているので、
古い受け取り方（`StandaloneInputModule`）を付けるとエラーになる。
**`InputSystemUIInputModule`** のほうを付けている。

## できていないこと・既知の問題

- **見た目の大きさや色は調整前の値。** 遊びながら詰めること
- **自動で用意される画面は、インスペクターの値が初期値のまま**になる。
  色や文字の大きさを変えたいシーンでは、`ポーズ画面を置く` で手で置くこと
- **フォントはパソコン任せ。** 游ゴシックなどが入っていないパソコンでは、
  別のフォントになるか、文字が四角になる可能性がある
- **キーボードやコントローラーでは選べない。** いまはマウス専用
- **設定は音量とマウス感度の2つだけ。** 画面の大きさや操作の割り当ては未対応
- **「ゲームをやめる」に確認画面が無い。** 押すとすぐ終了する
- **音は止まらない。** 音を入れたら、`GamePause` で `AudioListener.pause` も切り替えること
- 通信（マルチプレイ）には**未対応**。止めるのは自分の画面だけになる
