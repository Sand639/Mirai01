## この機能は何か

**カートの代わりに、ロボットが自分の足でコースを走るレース。**

**ルールはカートのレースとまったく同じ。**
カウントダウンのあとに走り出し、**コースを1周するとゴール**になる。
仕組みの説明は `レースのスタートとゴール.md` を読むこと。**ここには違うところだけ書く。**

> **カートのレースは残してある。** どちらも別のシーンとして並んでいるので、
> 見比べながら「どちらが面白いか」を決められる。

| | カートのレース | **走るレース（これ）** |
| --- | --- | --- |
| シーン | `RaceTest.unity` | **`RunnerRaceTest.unity`** |
| 走るもの | `RaceKart.prefab` | **`RobotRig.prefab`**（既存のロボット） |
| 1周の長さ | 約354m | **約148m**（走る速さに合わせて小さくした） |
| カメラ | 後ろから追うだけ | **ロボットのカメラ**（マウスで回せる。V で一人称） |
| できること | 走るだけ | **分離・合体・ジャンプ・持つ**が全部そのまま使える |

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| **W / A / S / D** | 走る |
| **マウス** | 視点を回す |
| **Space** | ジャンプ |
| **Q / Tab / E** | 切り離す／操作を切り替える／合体する |
| **V** | 一人称と三人称を切り替える |
| **R** | **やり直し**（スタート地点に戻る） |
| **Escape** | ポーズ画面 |

### **重力が時間で変わる**（このプロトタイプの目玉）

**8〜14秒ごとに、重力がランダムに変わる。**
軽いと**高く跳んで、ゆっくり落ちる。** 重いとほとんど跳べない。

変わる前に、画面の上に **「まもなく重力が変わる！」** が出る。
詳しくは `重力が時間で変わる.md` を読むこと。

**ロボットの操作は、これまでどおり全部使える。**
上半身だけ先に飛ばして進む、といった走り方もできる（**それが面白いかは、走ってみて決めること**）。

## 仕組み（分かる人向け）

### RobotRig のプレハブを変えていない

**ロボットのプレハブには手を付けていない。**
`RaceRacer` と `RobotRacerLink` は、**シーンに置いたものにだけ足してある。**

こうしないと、ロボットを使っている**他のシーン全部**にレース用の部品が付いてしまう。

### 「動いている体」を教える繋ぎ役が要る理由

ここが一番の違いで、**そのままでは1周を数えられない。**

ロボットは**入れ物（`RobotRig`）が動かず、中の体が動く**作りになっている。
しかも**合体中は「合体した体」、分離中は「上半身」か「下半身」**と、動く体が入れ替わる。

放っておくと、レース側は**動かない入れ物**を見続けて、
「ずっとスタート地点にいる」ことになってしまう。

そこで **`RobotRacerLink`** が毎フレーム、
**いま操作している体をレース側に教えている。**

| やっていること | なぜ |
| --- | --- |
| 位置を見る先を、操作中の体にする | 入れ物は動かないため |
| カウントダウン中とゴール後は操作を止める | フライングを防ぐため |
| やり直しで、**3つの体をまとめて**戻す | 分離したまま戻すと片方が置き去りになるため |

そのために、共通側にも2つだけ足してある。

- `RaceRacer` に「**位置を見る先**」と「**やり直しのやり方**」を差し替える口を作った
- `RobotController` に「**外から操作を止める**」スイッチ（`ControlSuspended`）を作った。
  **止めている間も重力は効く**ので、その場に立って待つ形になる

### 速さの出し方を変えた

画面右下の速度は、**位置の変化から計算している。**
カート専用の作りをやめたので、**走る人でも乗り物でも同じように出せる。**

### コースを小さくした

ロボットの走る速さは**毎秒5m**。カート（最高毎秒20m）の4分の1しかない。
同じコースだと**1周に1分以上**かかってしまうため、**1周148m**（30秒ほど）に縮めてある。

大きさは `RaceCourseSetup.cs` の `RunnerCourse` にまとまっている。

## できていないこと・既知の問題

- **走れることは確認済み**（2026/9/10、大槻さん）。**重力が変わる仕様のほうは未確認**
- **分離したまま走るとどうなるかが未確認。** 上半身だけで進めるので、
  **近道や壁越えができてしまう可能性がある**（通過点を順番に通る必要はあるので、周回自体はごまかせない）
- **やり直したとき、分離したままなら分離したまま戻る。** 上半身と下半身が並ぶので、**E を押せば合体できる**
- カートのレースにある**できていないこと**は、そのまま当てはまる（`レースのスタートとゴール.md`）
