## この機能は何か

**しばらく走っていると、重力がひとりでに変わる。**

**月面運動会（ロボットが走るレース）のメインの仕様。**
軽くなったり重くなったりするので、**同じコースでも走り方が変わる。**

| 段階 | 何が起きるか |
| --- | --- |
| **予告** | 画面の上に **「まもなく重力が変わる！」** が点滅する（初期値2秒） |
| **変化** | **じわじわ**新しい重力に変わる（初期値1.5秒） |
| **しばらく** | 次の予告まで、その重力のまま（初期値8〜14秒） |

新しい重力は、**あらかじめ用意しておいた候補の中から、ランダムに1つ**選ばれる。

### 重力の候補（初期値）

| 値 | だいたいの目安 |
| --- | --- |
| **1.6** | **月** |
| **3.7** | **火星** |
| 6.0 | 少し軽い |
| **9.81** | **地球（ふつう）** |
| 14.0 | 重い |

**候補はインスペクターで自由に足し引きできる。**
「月と地球だけ」にすることも、「軽いのばかり10個」にすることもできる。

> **同じ値を2つ入れると、その重力が出やすくなる。**
> 例えば地球を3つ入れておけば、「たまに変わる」くらいの手ざわりになる。

**同じ重力は続けて選ばれない**（`Avoid Same Twice`）。
続けて選ばれると「予告が出たのに何も変わらない」ことになるため。

## 遊ぶ人から見た動き

| 重力 | どうなるか |
| --- | --- |
| **軽い**（月くらい） | **高く跳んで、ゆっくり落ちてくる。** 走る速さは変わらない |
| ふつう | いつもどおり |
| **重い** | **ほとんど跳べない。** 落ちるのが速い |

**画面の上に、いまの重力が出る。**

```
重力  3.2　（軽い）
```

**跳び上がる強さは、重力が変わっても変わらない。**
変わるのは**落ちる速さだけ**なので、**軽いほど高く跳ぶ。**
「月面らしさ」が出るのはこのため。

## すぐ試す方法

1. Unityで `Assets/Scenes/Test/RunnerRaceTest.unity` を開く
2. **再生ボタンを押す**
3. しばらく走り回る。**8〜14秒ごとに重力が変わる**

すぐに試したいときは、`GravityShifter` の **Shortest / Longest Interval を 2 くらい**にすると分かりやすい。
**候補を「1.6 と 14」の2つだけ**にすると、軽い・重いの差がはっきり分かる。

## 自分のシーンで使う方法

**空のゲームオブジェクトを作って、`GravityShifter` を付けるだけ。**
つなぐものは無い。

## 設定できる値（インスペクターの項目）

`GravityShifter` を選ぶと調整できる。**重力は正の数で入れる**（下向きにするのは中でやっている）。

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| **Gravity Choices** | **重力の候補。この中から1つ選ばれる**（正の数で入れる） | 1.6 / 3.7 / 6 / 9.81 / 14 |
| **Avoid Same Twice** | **同じ重力が続けて選ばれないようにする** | ON |
| Shortest Interval | 次に変わるまでの、一番短い秒数 | 8 |
| Longest Interval | 次に変わるまでの、一番長い秒数 | 14 |
| Warning Seconds | **変わる前に予告を出す秒数。** 0で予告なし | 2 |
| Change Seconds | **変わりきるまでの秒数。** 0だと一瞬で変わる | 1.5 |
| Start Gravity | 始めるときの重力 | 9.81 |
| Log Changes | 変わるたびにコンソールに書き出す | ON |

## 仕組み（分かる人向け）

### `Physics.gravity` だけでは効かない

**ここが一番の落とし穴。**

Unityには最初から `Physics.gravity`（初期値 -9.81）がある。
けれど**これが効くのは、物理演算（Rigidbody）で動く物だけ。**

**このプロジェクトの人・ロボット・カートは `CharacterController` で動いていて、
落ちる速さは、それぞれのスクリプトが自分で計算している。**

つまり `Physics.gravity` をいくら変えても、**人は同じ速さで落ちてくる。**
「変えたのに何も起きない」となる。

そこで **`WorldGravity`** という入れ物を1つ置き、
**落ちる計算をしている場所が、みんなそこを見る**形にした。

```
GravityShifter（時間で変える）
        ↓
   WorldGravity（いまの値を持つ）
        ↓
RobotBody / PlayerController / KartController（落ちる速さに掛ける）
        ↓
   Physics.gravity（転がる物にも同じように効かせる）
```

**Rigidbody の物にも効かせたい**ので、`Physics.gravity` のほうも一緒に書き換えている。

### 落ちる速さだけ変えている

各スクリプトは、**自分の重力の値に `WorldGravity.Scale` を掛けている**だけ。

`Scale` は「**ふつうを1としたときの強さ**」で、月なら約0.17、地球なら1。
こうすると、**それぞれのスクリプトが持っていた手ざわり（例：ロボットは -20）を残したまま**、
軽い・重いだけを足せる。

**跳び上がる強さには掛けていない。**
掛けてしまうと、軽くても重くても**同じ高さまでしか跳べなくなり**、面白くないため。

### 急に変えない

一瞬で重力が変わると、**空中で急に落ちて事故になる。**
そこで `Change Seconds` の間をかけて、**始めと終わりをゆるやかに**しながら変えている。

### 元に戻すのを忘れない

重力は**ゲームを通してひとつしかない**値。
月の重力のまま再生を止めると、**次に始めたときも月のまま**になりかねない。

そのため、

- `GravityShifter` が消えるとき（シーンを抜けるとき）に**ふつうに戻す**
- 再生を始めたときにも、**必ずふつうから始める**

の2つを入れてある。

## できていないこと・既知の問題

- **まだ実際に遊んで確かめていない。** 候補の5つも間隔（8〜14秒）も**当てずっぽうの初期値**。走ってみて決めること
- **重力が変わっても、走る速さは変わらない。** 実際の月なら踏ん張りが効かず滑るはずだが、そこまでは真似ていない
- **音が鳴らない。** 予告は文字だけ。**音があったほうが絶対に分かりやすい**ので、音が入ったら足すこと
- **見た目が変わらない。** 軽いときに何か演出（色・空・ゆっくりした砂ぼこり）があると伝わりやすい
- **横向きの重力にはできない。** 上下だけ
- **通信（マルチプレイ）には未対応。** いまのままだと**各自の画面が別々の重力になる。**
  対戦にするなら、**ホストが決めた値を配る**必要がある（`リスクリスト.md` に登録済み）
- **持ち上げた物や、切り離した上半身の飛び方**への効き具合は未確認
