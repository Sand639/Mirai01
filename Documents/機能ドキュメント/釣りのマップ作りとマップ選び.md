## この機能は何か

**釣りのオンライン対戦で遊ぶマップを、何枚でも増やせるようにした。**

- メニューを1回押すと、**遊ぶのに必要な部品が入ったマップの雛形**ができる（`FishingMap01`、`FishingMap02`…）
- 雛形の床・壁・障害物を Unity 上で**自由に作り変えてよい**。ツールがあとから上書きすることはない
- 作ったマップは、**ロビーでホストが選べる**。参加者の画面にも、選ばれたマップの名前が出る

> 以前からある会場 `FishingOnline.unity` は、ツール（`釣りのオンライン用シーンを作る`）で**毎回まるごと作り直される**。
> 手で描き足しても消えるので、**マップ作りには使わないこと。** 新しいマップはこの機能で作る。

## 遊ぶ人から見た動き

| 場面 | どうなるか |
| --- | --- |
| ロビーに入る（ホスト） | 「■ マップ」の下に、**選べるマップがボタンで並ぶ**。選んでいるものに「●（選択中）」が付く |
| ロビーに入る（参加者） | 「■ マップ」の下に、**ホストが選んだマップの名前**が出る（参加者は選べない） |
| ホストが「ゲーム開始（◯◯ へ全員で移動）」を押す | 全員が選んだマップへ移動する |
| 結果画面から「ロビーへ戻る」 | ロビーに戻る。**選んでいたマップは覚えている** |

選べるマップは次の2種類。**どちらもビルドの一覧（`File > Build Profiles`）に入っているものだけ**が並ぶ。

- 最初からある会場 `FishingOnline`
- 名前が **`FishingMap`** で始まるシーン

## マップの作り方（手順）

### 1. 雛形を作る

1. Unity で、Console に赤いエラーが無いことを確かめる
2. メニュー **`Tools > Mirai01 > 釣りの新しいマップを作る（オンライン）`** を押す
3. `Assets/Scenes/Test/FishingMap02.unity` のように、**まだ使われていない番号**でマップができて開く
   - **すでにあるマップは上書きしない**（番号をずらして新しく作る）
   - ビルドの一覧への登録も自動で行われる
4. Console に「【マップの点検】✔ 遊ぶのに必要な物はそろっています。」が出れば成功

> **`FishingMap01` は作成済み（2026/9/15）。** 1枚目はこれを作り変えればよい。

### 2. 作り変える

Hierarchy はこう分かれている。

| まとまり | 中身 | 触ってよいか |
| --- | --- | --- |
| **`Stage`** | 床（`Ground`）、四方の壁、ゴール4つ（`Wall_North` など） | **自由に作り変えてよい**（ただし下の「守ること」を見る） |
| **`Obstacles`** | 動く障害物の見本（`Obstacle_Sample`） | **自由に**。要らなければ消してよい |
| `FishingMatch` | 試合のまとめ役 | **消さない** |
| `FishingHUD` | 点数・残り時間・結果の表示 | **消さない** |
| `Main Camera` | 自分のプレイヤーを追う見下ろしカメラ | **消さない**（高さや角度は変えてよい） |
| `FishingObjectSpawner` | 物資と爆発物を降らせる係 | **消さない**（範囲や割合は変えてよい） |
| `HookUI` | チャージとスキルチェックのゲージ | **消さない** |
| `Directional Light` | 明かり | 自由に |

### 3. 点検する

作り変えたら、**Ctrl+S で保存してから** メニュー **`Tools > Mirai01 > 開いている釣りマップを点検する`** を押す。
問題があれば、画面と Console に「直したほうがよい所」が出る。

### 4. 遊んで確かめる

1. **`Tools > Mirai01 > 釣りのオンライン検証用のビルドを作る`**（`FishingMap〜` のマップも自動でビルドに入る）
2. `Mirai01/Build/FishingOnlineTest/4人で自動接続.bat` を実行
3. ホストの窓（最初の窓）のロビーでマップを選び、「ゲーム開始」

> エディタの再生で1人だけ確かめる場合は、`FishingLobby.unity` を開いて再生し、「1人で練習する（通信を使わない）」を押してから、ロビーでマップを選ぶ。

## マップを作るときに守ること

**点検のメニューが、ほとんど自動で見てくれる。** 理由も書いておく。

| 守ること | 理由 |
| --- | --- |
| **ゴール（`Pocket_North` などの `FishingNetPocket`）は4つのまま。** 各ゴールの **Pocket Index を 0〜3 で1つずつ**使う | チーム分けのルール（`FishingTeams.cs`）が「ゴール4つ」で決まっている。**場所は動かしてよい** |
| ゴールは**丸ごと動かす**（`Wall_North` の中の `Pocket_North` と `Pad` を一緒に） | `Pad` がチームの色に塗られる床。離すと色だけ別の場所に出る |
| **中心 (0, 0) から半径 6m の円の上に、高さ0の床を置き、ふさがない** | プレイヤーは**この円の上に8か所**並んで出てくる。**マップ側では変えられない** |
| 床は高さ0に置く。**高さ -5m より下に落ちた物は消える** | 物資の「場外に落ちたら消える」の決まり |
| 広さを変えたら、`FishingObjectSpawner` の **Area Half Size** も合わせる | 範囲が合っていないと、壁の中や場外に物資が降る。スポナーを選ぶとシーン画面に範囲の枠が出る |
| 動く障害物と壁のあいだは **1m 以上** あける | 挟まるとプレイヤーがめり込む（`リスクリスト.md`） |
| **`NetworkManager` やプレイヤーを置かない** | どちらもロビーから連れてくる。置くと2つになって壊れる |
| **シーンの名前は `FishingMap` で始める** | ロビーはこの名前でマップを探す |

### 動く障害物の足し方

`Obstacle_Sample` を選んで **Ctrl+D で複製**し、位置と **Points（通る場所）** を変えるのが一番簡単。
障害物の設定は `釣りの動く障害物.md` を参照。**通信の部品は要らない**（そのまま置けば全員の画面で同じ動きになる）。

### マップの名前を変える・複製する

- 名前は **Unity の Project 画面で**変える（OSのエクスプローラーで変えない。`.meta` との対応が壊れる）
- **`FishingMap` で始まる名前**にする（例：`FishingMapIsland`）
- 変えたあと・複製したあとは、**`Tools > Mirai01 > 釣りのマップをビルドの一覧に登録し直す`** を押す
  - ビルドの一覧に入れ直し、**通信の部品の番号**（下の「仕組み」）が抜けていれば付けてくれる
  - 名前を変える前の古い行が一覧に残っていたら、`File > Build Profiles` で消してよい

> **マップのシーンは自動で合体（マージ）できない。** 同じマップを2人で同時に触らないよう、Discord で一声かけること。

## 仕組み（分かる人向け）

- **マップの候補**：`FishingLobbyUI.GetAvailableMaps()` が `SceneManager.sceneCountInBuildSettings` を回し、
  `gameSceneName` と一致するか `mapScenePrefix` で始まるシーン名を集める。ビルドの一覧に無いシーンは Netcode で読み込めないので、はじめから出さない。
- **選んだマップを配る**：`FishingLobbyUI` は通信の部品ではないので値を配れない。そこで **ホストのプレイヤー（`FishingNetPlayer`）に
  `NetworkVariable<FixedString64Bytes> lobbyMapName`** を持たせた。ホストはロビーにいる間 `Update` で書き続け、参加者は `FishingNetPlayer.HostSelectedMap` で読む。
  NetworkVariable なので**あとから入った人にも自動で届く。**
- **通信の部品の番号（`GlobalObjectIdHash`）**：シーンに置いた `NetworkObject`（`FishingMatch` とゴール4つ）は、この番号で全員のPCで対応づけられる。
  番号は Netcode の `OnValidate` が付けるが、**シーンが保存される前は付けられない**（0 のまま）。
  さらに**開き直すとメモリ上では付くが、「変更あり」にならないので保存されない。**
  そこで雛形作りでは、保存 → 開き直す → `OnValidate` を呼ぶ → **必ず `MarkSceneDirty` して保存**、としている（`EnsureNetworkIdsInScene`）。
  Unity で普通に作ったり Ctrl+S したりしたシーンでは、この問題は起きない。
- **点検**：`CheckOpenMap()` が、試合のまとめ役・表示・カメラ・ゴール4つ（番号の重複）・スポナーのプレハブ（オンライン用か）・
  番号が 0 の NetworkObject・置いてはいけない物（`NetworkManager`・プレイヤー）・プレイヤーの出てくる8か所（上から `Raycast` して床の高さを見る）・ビルドの一覧を調べる。

## できていないこと・既知の問題

- **⚠ 遊んでの確認がまだ。** ロビーでマップを選んで全員が移動するところ、参加者の画面にマップ名が出るところは、ビルドを4つ起動して確かめる必要がある。
- **プレイヤーが出てくる場所をマップごとに変えられない。** 中心から半径 6m の円で固定（`FishingNetPlayer.MoveToSpawnPoint`）。
  マップの形によっては不便なので、必要になったら「出てくる場所の目印をマップに置く」形にするとよい。
- **ゴールは4つで固定。** 数を変えるには `FishingTeams.cs` のルールから変える必要がある（企画の判断）。
- **マップを選べるのはホストだけ。** 投票などは無い。
- マップ選びの画面は仮（`OnGUI`）。本番のロビー画面を作るときに作り直す。
- `FishingMap01` は雛形のまま（既存の会場と同じ形 ＋ 見本の障害物1つ）。
