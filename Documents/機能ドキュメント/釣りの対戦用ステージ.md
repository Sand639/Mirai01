## この機能は何か

**オンライン対戦のために、形を作り込んだマップを1枚作るツール。**

これまでのマップ（`FishingMap01` `FishingMap02`）は、床と壁とゴールだけの**まっさらな雛形**だった。
そこに「**広い面でプレイヤーをまとめて足止めする**」置き方をした障害物を入れたものが、この対戦用ステージ。

メニューを1回押すと `Assets/Scenes/Prototype/Fish/FishingMapBattle01.unity` ができて、
そのまま**ロビーのマップ選びに出てくる**（名前が `FishingMap` で始まるため）。

> マップの作り方・選び方そのものは `釣りのマップ作りとマップ選び.md` と同じ。
> こちらは**中身の置き方**を決めたもの。

## どんな形か

床は今までどおり **40m × 40m**。真上から見るとこうなっている。

```
              ゴール（北）
      ┌────────■■■────────┐
      │  ←───── 遮り ─────→ │
      │    ＼           ／   │
 ゴ ■ │     ＼   中央   ／   │ ■ ゴ
 ｜   │      （空ける）      │   ｜
 ル   │     ／           ＼  │   ル
      │    ／             ＼ │
      │  ←───── 遮り ─────→ │
      └────────■■■────────┘
              ゴール（南）
```

| 物 | 名前 | 何をするか |
| --- | --- | --- |
| **斜めの大きな壁**（＼／） | `Block_NE` `Block_SE` `Block_SW` `Block_NW` | **動かない。** 長さ15m。四隅の対角線をふさぐ |
| **ゴールの前を横切る遮り** | `Shutter_North` `Shutter_East` `Shutter_South` `Shutter_West` | **動く。** 長さ11mの板が左右（南北）に動き、**端まで行くと1秒止まる** |
| **中央** | （何も置かない） | 半径6mの円。**プレイヤーが出てくる場所**なので必ず空ける |

### ねらい（なぜこう置いたか）

1. **斜めの大きな壁**が対角線をふさぐので、中央と外側の行き来は**北・東・南・西の4つの門だけ**になる。
   門の幅は約4.5mで、ゴールの入口（5m）とほぼ同じ。まっすぐ突っ切れないぶん、どの道を通るかの読み合いが生まれる。
2. **ゴールの前を横切る長い遮り**が、ゴールの正面を**広く覆う**。
   左右に8mずつ動くので、**幅27mぶんを1枚の板が行ったり来たりする**。端で止まっているあいだだけ正面が開く。
3. それでも**中央と四隅は広く空けてある**ので、逃げ場が無くならない。

**4つの門も4つの遮りも、同じ形・同じ動き**にしてある。
ゴールはチームごとに割り当てられる（`釣りのオンライン対戦.md`）ので、
**どのチームのゴールでも条件が同じ**になるようにした。

## 遊ぶ人から見た動き

| 場面 | どうなるか |
| --- | --- |
| 試合が始まる | 中央の円の上に、全員が並んで出てくる |
| 中央から外へ出る | 斜めの壁があるので、**北・東・南・西のどれかの門を通る**ことになる |
| ゴールへ近づく | ゴールの正面を、長い遮りが横切っている。**当たると通れず、押し出される** |
| 遮りが端で止まる | **4か所いっせいに**、ゴールの正面が1秒ほど開く。ここが入れどき |
| 遮りの内側の細い道 | 遮りと斜めの壁のあいだ（約1.2m）は、いつでも通り抜けられる。**横に移動する道**として使える |
| 四隅 | 何も置いていない広場。物資はここにもよく落ちる |

## 作り方（手順）

1. Unity で、Console に赤いエラーが無いことを確かめる
2. メニュー **`Tools > Mirai01 > 釣りの対戦用マップを作る（大きな遮り）`** を押す
3. `Assets/Scenes/Prototype/Fish/FishingMapBattle01.unity` ができて開く
   - **すでにあれば番号をずらして新しく作る**（`FishingMapBattle02`…）。上書きはしない
   - ビルドの一覧への登録も自動で行われる
4. Console に「【マップの点検】✔ 遊ぶのに必要な物はそろっています。」が出れば成功

### 遊んで確かめる

1. **`Tools > Mirai01 > 釣りのオンライン検証用のビルドを作る`**
2. `Mirai01/Build/FishingOnlineTest/4人で自動接続.bat` を実行
3. ホストの窓のロビーで **`FishingMapBattle01`** を選び、「ゲーム開始」

> 1人で形だけ見たいときは、`FishingLobby.unity` を再生 →「1人で練習する（通信を使わない）」→ マップを選ぶ。

## 設定できる値

### 置いたあとに Unity 上で変える

シーンを開いて、`Stage` の中の `Block_〜` や `Obstacles` の中の `Shutter_〜` を選べば、
**位置・大きさ・動く道すじを自由に変えてよい。**（一度作ったシーンを、ツールが上書きすることはない）

遮りの動きは `MovingObstacle` の項目で変える。詳しくは `釣りの動く障害物.md`。

| 項目名 | 意味 | このステージの値 |
| --- | --- | --- |
| Points | 通る場所（置いた位置からのずれ） | 左右（南北）に **±8m** |
| Move Speed | 動く速さ | **4**（m/秒） |
| Wait Seconds | 端で止まっている秒数 | **1** |
| Ease In Out | 動き出しと止まる直前をゆっくりにする | **ON** |

### ツールが作る形そのものを変える

`FishingMapSetup.cs` の上のほうにある定数を書き換えると、**次に作るシーンの形**が変わる。

| 定数 | 意味 | 値 |
| --- | --- | --- |
| `BlockOffset` | 斜めの壁を、中心からどれだけ離すか | 8 |
| `BlockLength` / `BlockThickness` | 斜めの壁の長さ・厚み | 15 / 1.2 |
| `ShutterLine` | 遮りを、中心からどれだけ離すか | 15.5 |
| `ShutterLength` / `ShutterThickness` | 遮りの長さ・厚み | 11 / 1.2 |
| `ShutterTravel` | 遮りが中央からどこまで動くか（片側） | 8 |
| `ShutterSpeed` / `ShutterWaitSeconds` | 遮りの速さ・端で止まる秒数 | 4 / 1 |

## 仕組み（分かる人向け）

- **マップを作る処理は1つにまとめた。** `FishingMapSetup.CreateMap()` が、床・壁・ゴール・試合の仕組み・カメラ・スポナー・UI を置く。
  **マップごとに違うのは「床の上に何を置くか」だけ**なので、そこを `System.Action<Transform, Transform>` で外から渡す形にした。
  - 雛形 … `BuildTemplateStage`（見本の障害物1つ）
  - 対戦用 … `BuildBattleStage`（斜めの壁4枚＋遮り4つ）
  - **新しい形のステージを足すときも、`Build〜Stage` を1つ書いてメニューを1行足すだけでよい。**
- **遮りは通信していない。** `MovingObstacle` は位置を「全員で共有している時計」から計算しているので、
  `NetworkObject` を付けなくても全員の画面でそろう（`釣りの動く障害物.md`）。
- **斜めの壁は Y 軸だけ45度回してある。** `MovingObstacle` は傾けると壊れるが、こちらは動かないただの箱なので問題ない。
- **重なり（めり込み）が起きない寸法にしてある。**
  - 遮りどうし … 一番伸びたときで 13.5m。となりの遮りは 14.9m から始まるので **1.4m あく**
  - 遮りと斜めの壁 … **1.2m あく**（動く物と壁のあいだは1m以上、という決まり。`リスクリスト.md`）
  - 遮りと外の壁 … **2.4m あく**
  - 斜めの壁と中央の円 … 一番近い所で **4.7m あく**（プレイヤーの出てくる場所をふさがない）

## できていないこと・既知の問題

- **⚠ 遊んでの確認がまだ。** 特に次の3つは、実際に4人で動かしてみないと分からない。
  - 門の幅（約4.5m）が、逃げ回るのに狭すぎないか
  - 遮りが開いている1秒が、物資を投げ入れるのに短すぎないか
  - 遮りと斜めの壁のあいだの細い道（約1.2m）で、**挟まって動けなくならないか**
- **物資が降る範囲は中心から ±16m のまま。** 四隅にも遮りの外側にも降る。多すぎる／少なすぎると感じたら
  `FishingObjectSpawner` の Area Half Size で変えられる（`釣りの物資のスポナー.md`）。
- **遮りは4つとも同じ動き（同じタイミング）。** 「1か所ずつ順に開く」形にしたい場合は、
  `MovingObstacle` の Start Offset Seconds をゴールごとにずらす。ただし**チームごとの有利不利が出る**ので、企画の判断が要る。
- 置き場所は `Assets/Scenes/Test/`。**プロトタイプのステージは `Assets/Scenes/Prototype/`** という決まりがあるので、
  `develop` を取り込んだときにまとめて移すこと（`釣りのマップ作りとマップ選び.md` と同じ状況）。
