## この機能は何か

**釣り竿のようなフックで、フィールドに落ちている「物資」を引っ掛けて、頭の上を通り越すように引き抜き、
タイミングよく入力して投げ飛ばす**遊びの土台。
「Last Shark Standing」のようなフック・投擲アクションを参考にしている。

見下ろしに近い視点の3D。プレイヤーはいつもマウスカーソルの方を向く。
投げた物資を**四方の壁にあるポケット**に入れると点数が入る。
物資の中には**爆発物**が混ざっていて、釣り上げると5秒後に爆発する。

見た目より**操作感と基本の流れ**を優先した、調整前のプロトタイプ。

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| WASD | 地面を移動する（スタン中は動けない） |
| マウスを動かす | プレイヤーがカーソルの方向を向く（この向きが「前」） |
| 左クリックを押す | フックを構える。押している間、下のバーがたまっていく（チャージ） |
| 左クリックを離す | カーソル方向へフックが飛ぶ。飛距離はチャージ量で決まる（最大値あり） |
| フックが物資に当たる | 物資が**弧を描いて浮き上がりながら**引き寄せられ、スキルチェックのゲージが動き出す |
| 引き寄せ中に左クリック | 押した瞬間のゲージ位置で、**投げる強さと方向**が決まる |
| ゲージが通り過ぎる／枠の外で押す | **ミス。** ほんの少しだけ引き寄せて、その場で終わる |

### 引き寄せの動き

物資は「釣り竿で引っこ抜く」ように動く。

| ゲージの位置 | 物資はどこにいるか |
| --- | --- |
| 0（左端） | 釣り上げた場所 |
| 0.5（真ん中） | **プレイヤーの真上** |
| 1（右端） | プレイヤーの**後方へ抜けたところ** |

### スキルチェック（枠は2つ）

ゲージは**1回だけ**左から右へ動く。枠は2つあり、**どちらで押したかで飛ぶ方向が変わる。**

| 枠 | 位置 | 色 | 押したときに飛ぶ方向 |
| --- | --- | --- | --- |
| 前半 | 真ん中より手前（初期値 0.27） | 青 | **プレイヤーの後方** |
| 後半 | 真ん中より奥（初期値 0.73） | 橙 | **プレイヤーの前方（進行方向）** |

枠の中心に近いほど強く投げる。

| 枠の中のどこで押したか | 強さ | 見た目 |
| --- | --- | --- |
| 外側（通常成功） | 普通の力 | 枠の色 |
| 中ほど（良いタイミング） | 強い力 | 黄 |
| ほぼ中心（最適なタイミング） | 非常に強い力 | 緑 |

**投げる方向は「投げた瞬間にプレイヤーが向いている方向」を基準にする。**
釣り上げたときの向きではないので、引っ張っている間に振り向けば行き先も変わる。

### ポケットと点数

四方の壁の中央が切り欠かれていて、その奥にポケットがある。
**投げた物資がポケットに入ると点数が入り、床が緑に光る。**
入った物資は消えて、少しあと（初期値6秒）に元の場所へ戻ってくる。

- フックで引っ張っている最中の物資は数えない（引きずり込みで稼げないようにするため）
- 爆発物は点数が0なので、ポケットに入れても点にならない
- **ポケットには「誰のものか」を表すプレイヤー番号を持たせてある。**
  いまは全部プレイヤー1のものだが、人が増えたら番号を振り分けるだけで運び先を分けられる

### 爆発物

黒くて上に導火線が立っている箱が爆発物。

| 起きること | 内容 |
| --- | --- |
| 釣り上げる | 導火線に火がつく（初期値5秒）。**離しても投げても止まらない** |
| 残り時間が減る | **点滅が速くなり、脈打つように大きく縮む。** 画面上部に「爆発まで◯.◯秒」が出る |
| 爆発 | ふくらんで縮む火球と閃光が出る |
| 爆発に巻き込まれた物資 | **消滅する**（少しあとに元の場所へ戻ってくる） |
| 爆発に巻き込まれたプレイヤー | **2秒スタン。** 体が赤く点滅し、頭の上に赤い印が出て、画面中央に「スタン中！」と出る |

スタン中は移動とフックの操作ができない（向きを変えることはできる）。

## 検証シーンの作り方・確かめ方

**検証シーンは2つある。作るツールも2つに分かれていて、片方を作っても、もう片方は上書きされない。**

| メニュー | できるシーン | 中身 |
| --- | --- | --- |
| `Tools > Mirai01 > 釣りフックの検証シーンを作る` | `FishingHookTest.unity` | **基本。** フックの操作だけを確かめる最小構成。まっすぐな壁、物資6個 |
| `Tools > Mirai01 > 釣りフックのステージ検証シーンを作る` | `FishingArenaTest.unity` | **ステージ。** ポケット・スコア表示・爆発物2個・物資8個 |

手順

1. Unityで、スクリプトのコンパイルが通るのを待つ（Consoleに赤エラーが無いこと）。
2. 上のどちらかのメニューを実行する。
3. できたシーンが開く（自動で開かなければ、`Assets/Scenes/Test/` からダブルクリックで開く）。
4. 再生ボタンを押す。操作方法は画面下に出る。

> **どちらのシーンも同じスクリプトで動く。** 引き寄せの軌道・スキルチェック・投げる向きは共通なので、
> 2つのシーンの違いは「ステージに何が置いてあるか」だけ。
> 片方のシーンだけ挙動を変えたい場合は、**そのシーンに置いたコンポーネントの数値**を変えること。

> **メニューを実行しても変わらないと感じたら**、まず Console を見ること。
> ①赤エラーが出ているとコンパイルが通らず、**古い状態のまま動く。**
> ②実行に成功すると「【基本】…を作りました」「【ステージ】…を作りました」というログが出る。
> **このログが出ていなければ、ツールは走っていない。**
> ③開いているシーンが古いままのことがあるので、`Assets/Scenes/Test/` から開き直す。

このシーンは**検証用なので、ビルド（`File > Build Settings` のシーン一覧）には入れない**こと。

## 設定できる値（インスペクターの項目）

### HookController（フックの発射）※プレイヤーに付いている

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Charge Time | 押しっぱなしでチャージ最大になるまでの秒数 | 1.0 |
| Min Range / Max Range | チャージ0とチャージ最大のときの飛距離（m）。Max が飛距離の最大値 | 4 / 16 |
| Fly Speed / Return Speed | フックが伸びる速さ／戻る速さ（m/s） | 30 / 45 |
| Hook Cast Radius | 当たりを見る球の半径。大きいほど引っ掛けやすい | 0.35 |

### ThrowController（引き寄せとスキルチェック）※プレイヤーに付いている

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Skill Check Duration | 引き寄せ〜スキルチェックが終わるまでの秒数。短いほど難しい | 1.6 |
| Overhead Height | プレイヤーの足元から、物資が通り越す高さ（m） | 2.6 |
| Pass Distance | 真上を通ったあと、後方どれだけまで抜けるか（m） | 3.5 |
| Arc Lift | 弧の膨らみ | 0.8 |
| Reel Spin Speed | 引き寄せ中に物資を回す速さ（度/秒） | 200 |
| **Skill Check Zones** | **スキルチェックの枠の一覧。増やせばそのまま枠が増える** | 2つ |
| └ Label / Center | 名前／ゲージ上の中心（0〜1） | 前半 0.27／後半 0.73 |
| └ Hit / Good / Perfect Window | 通常成功／強い／非常に強い、になる範囲（中心からの片側の広さ） | 0.11 / 0.06 / 0.022 |
| └ Direction | この枠で成功したときに飛ばす方向 | 前半 Backward／後半 Forward |
| Throw Force Normal / Good / Perfect | 各段階の投げる力 | 8 / 14 / 22 |
| Throw Lift | 投げるときに少し上向きに加える力（0で真横） | 2 |
| Miss Pull Force | ミスしたときにプレイヤー側へ引き寄せる力 | 2.5 |

> **枠を増やすとき**は `Skill Check Zones` に足すだけでよい。
> ただし**画面の表示は2枠ぶんしか作られていない**ので、3枠以上にするときは
> `FishingSceneBuilder.cs` の `ZoneVisualCount` を増やして検証シーンを作り直すこと。

### ExplosiveObject（爆発物）※黒い箱に付いている

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Fuse Seconds | 釣り上げられてから爆発するまでの秒数 | 5 |
| Explosion Radius | 爆発が届く範囲（m） | 4.5 |
| Player Stun Seconds | 巻き込まれたプレイヤーが動けなくなる秒数 | 2 |
| Min / Max Blink Per Second | 火がついた直後／爆発直前の点滅回数 | 1.5 / 16 |
| Max Pulse Scale | 爆発直前に何倍まで膨らむか | 1.3 |

### HookableObject（物資）／ScorePocket（ポケット）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Score Value | ポケットに入れたときの点数。0でポケットが無視する | 物資 1／爆発物 0 |
| Respawn Seconds | 消えてから元の場所に戻るまでの秒数。0で戻らない | 物資 6／爆発物 8 |

## 仕組み（分かる人向け）

- **狙点の共有**：`PlayerAimController` がカメラからマウスへレイを飛ばし、地面との交点を `AimPoint`、
  そこへの水平な向きを `AimDirection`（＝「前方向」）として公開する。移動の向き・フックの発射・投げの方向は、
  すべてここを読む。方向の定義を1か所にまとめてあるので、方向の追加・変更がしやすい。
- **状態管理**：`HookController` が `Idle / Charging / Flying / Returning / Attached` の5段階を持つ。
  フックの飛び方（等速で前進、`SphereCast` で当たり確認、最大距離で折り返し）はここで計算し、
  `HookProjectile` は「物資に触れた」ことを報告するだけの薄い部品にしている。
- **引き寄せは物理ではなく決まった軌道**：ゲージの真ん中で必ずプレイヤーの真上に来るように揃えたいので、
  引き寄せ中は物資の Rigidbody を一時的にキネマティック（物理を止めた状態）にして、
  `ThrowController.UpdateReelPosition()` が位置を直接決めている。
  投げる瞬間に物理を元へ戻し、`AddForce(..., Impulse)` で飛ばす。
  行き先はプレイヤーの現在位置から毎フレーム取り直しているので、引き寄せ中に動いてもついてくる。
- **スキルチェックは枠のデータで表す**：`SkillCheckZone` が「ゲージ上の位置・広さ・投げる方向」を持つ。
  `ThrowController` は枠の配列を順に見て、押された位置がどの枠に入ったかで強さと方向を決める。
  **枠を足せば、そのまま新しいタイミングと方向が増える**（仕様7への対応）。
  `ResolveDirection(mode, tier)` は強さの段階も受け取っているので、
  「最適なタイミングのときだけ別方向へ」といった分岐もここ1か所で足せる。
- **消滅と復活**：`HookableObject.Vanish()` が見た目と当たり判定を消して、一定秒後に元の場所へ戻す。
  ポケットに入ったときと、爆発に巻き込まれたときの両方で同じ仕組みを使っている。
  プロトタイプで物資が尽きて遊べなくならないようにするため。
- **既存 PlayerRig の扱い**：体の見た目は `PlayerRig.prefab` を複製して使うが、
  中に入っている一人称/三人称のマウス視点操作（`PlayerController` / `PlayerViewSwitcher`）と内蔵カメラは
  見下ろしと噛み合わないので、生成ツールが**取り除いている**。`PlayerRig.prefab` 本体は変更していない。
  **`enabled = false` で無効化するだけでは足りない**（`Awake` が走ってマウスカーソルを画面中央に
  固定してしまい、見下ろしの照準が効かなくなる）。

## できていないこと・既知の問題

- **見た目は仮**。プレイヤー・フック・物資・爆発・ポケットはすべて Unity の基本形状で、調整前。
- フックが壁に当たっても止まらず、すり抜けて戻る（プロトタイプのため未対応）。
- 引き寄せ中は物資の物理を止めているため、**壁や他の物資をすり抜ける**。
- 火のついた爆発物の一覧を `ExplosiveObject.LitBombs`（静的な一覧）で持っている。
  画面のカウントダウン表示を簡単にするためのプロトタイプ用の作りで、数が増えたら作り替えが必要。
- タイミング判定・力・距離・爆発の数値は**未調整**。操作感を見ながら Inspector で詰める前提。
- 点数はシーンを再生し直すとリセットされる（保存しない）。
- スキルチェックの枠を3つ以上にすると、**画面の枠表示が足りなくなる**（上の注記を参照）。
- `Assets/Scripts/Fishing/` フォルダを新規作成した（既存の機能別フォルダの並びに合わせたが、
  フォルダ新規作成は事前確認の決まりのため `質問リスト.md` に事後登録済み）。
